# Expense Tracker

A command-line of expense tracker built in Python as my very first project
on the path to becoming an AI native engineer.

## Features

- Add expenses with amount, category, description, and date
- List all expenses and see the total
- Spending summary by category
- Data saved automatically to a JSON file
- Input validation for bad amounts

## How to run

1. Install Python 3
2. Clone this repo
3. Run: `python3 tracker.py`

## What I learned

- Variables, dictionaries, lists, and loops
- Functions and organizing code
- Reading and writing JSON files
- Handling errors with try/except
- Using Git and GitHub from day one
